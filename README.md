# 🏄 Surf - 冲浪小游戏

复刻 Edge 浏览器断网时的冲浪小游戏（Chrome Dino 风格），纯 HTML + Canvas 实现，无任何依赖。

## 玩法

- **↑ / ↓**（或 `W` / `S`）：切换泳道（上 / 中 / 下）
- **← / →**（或 `A` / `D`）：左右微调位置
- **空格**：开始 / 重新开始
- 手机端可直接点击屏幕或使用屏幕上的方向按钮

## 障碍与道具

| 图标 | 说明 |
| --- | --- |
| 🐦 海鸥 | 出现在上泳道 |
| 🌴 棕榈岛 | 出现在中泳道 |
| 🦑 海怪触手 | 出现在下泳道 |
| 🐚 贝壳 | 拾取 +50 分 |

速度会随时间逐渐加快，得分 = 前进距离 + 贝壳加分。最高分保存在本地浏览器中。

## 在线游玩

https://<你的用户名>.github.io/surf-game/

## 本地运行

直接用浏览器打开 `index.html` 即可，或：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
